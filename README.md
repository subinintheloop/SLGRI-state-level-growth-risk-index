# SLGRI-state-level-growth-risk-index
Open framework for comparing Indian states on economic growth, governance quality, and workforce risk
The State-Level Growth–Risk Index (SLGRI) is an independent, open research project that ranks Indian states and union territories on a composite risk-growth framework built on three pillars — Economic Risk, Governance Risk, and Workforce Risk.
Built using data from MOSPI, NCRB, and RBI state accounts. All indicators are normalised for cross-state comparability. The methodology, scoring logic, and full dataset are publicly available here.
This is a living project. Version 2 is in development — incorporating updated GSDP data, HDI in the human capital pillar, and a more granular crime risk dimension.
Collaboration, critique, and forks are welcome.
